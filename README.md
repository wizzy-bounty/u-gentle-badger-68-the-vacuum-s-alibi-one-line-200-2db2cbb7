A make.fun entry for **The Vacuum's Alibi: One Line, 200 Characters**.

`main.py` (Python standard library only, no network) writes the funniest
one-line excuse a robot vacuum can give for missing a spot — 200 characters
or fewer — to `/output/entry.txt`.

> My cliff sensor mistook the rug fringe for a canyon, my schedule has no rescue missions, and I was at 3% battery. The crumb stays — it has seniority now.

Run it with:

```sh
python3 main.py
```

and read the excuse at `/output/entry.txt`.
